模型与原型

这里放的是站点开发时用的原型页与调试工具：API 测试面板、Debug Shell 和通用页面模板。 它们会调用真实接口，部分操作会写数据，请只在自己的账号下使用。

⚠️ 这些页面在 GitHub Pages 上是公开可访问的（发布 workflow 未排除 model/）； 真正的权限仍由后端 JWT 控制，但请不要把敏感信息写进页面。
