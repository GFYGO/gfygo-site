隐私政策

最后更新日期：2026-10-21

1. 适用范围

本隐私政策适用于 GWL Works Lab（以下简称“我们”）提供的网站及相关服务。我们由个人运营，前端部署于 GitHub Pages，后端服务器位于中国大陆境内的阿里云服务器。

你使用本平台服务，即表示你已阅读并理解本隐私政策。

2. 我们收集的信息

我们可能收集以下信息：

  1. 账号信息：如用户名、邮箱、密码哈希、注册时间等；
  2. 使用数据：如访问日志、IP 地址、浏览器类型、设备信息、页面访问记录、API 调用记录；
  3. 内容数据：如你创建的文档、分组、笔记、上传文件或提交的内容；
  4. 第三方嵌入数据：当你使用 Desmos 等第三方学习工具时，相关第三方可能通过其自身机制收集你的使用数据，具体以其隐私政策为准；
  5. 未来功能数据：如未来开通代码执行、AI 服务、充值或 API Key 管理，可能涉及代码片段、模型调用记录、充值记录、API Key 标识信息等。

我们遵循最小必要原则收集信息，仅用于提供服务、保障安全、优化体验和履行法律义务。

3. 我们如何使用信息

我们使用你的信息用于以下目的：

  1. 提供文档、分组、嵌入、API 等服务；
  2. 验证身份、管理账号和保障服务安全；
  3. 排查故障、防止攻击、滥用或恶意占用资源；
  4. 改进产品功能和使用体验；
  5. 响应你的请求或处理投诉；
  6. 履行法律法规要求的义务。

4. 信息共享与披露

我们不会出售你的个人信息。除以下情形外，我们不会主动向无关第三方提供你的个人信息：

  1. 获得你的明确同意；
  2. 为提供服务所必需的服务提供商，例如云存储、日志分析、邮件通知等；
  3. 嵌入的第三方学习工具或 API 提供方，在你主动使用时可能接收必要数据；
  4. 法律法规要求、司法机关或行政机关依法要求；
  5. 为保护平台、用户或公众安全所必需。

5. 数据存储与安全

我们将采取合理可行的技术和管理措施保护你的信息，例如 HTTPS 传输、访问控制、日志监控、密码加密存储和定期备份。

但网络环境存在固有风险，我们无法保证信息绝对安全。因以下原因导致的信息泄露、丢失或损坏，我们不承担责任：

  1. 你未妥善保管账号、密码或 API Key；
  2. 你主动公开或向他人泄露个人信息；
  3. 第三方攻击、病毒、钓鱼、木马等非平台故意或重大过失原因；
  4. 不可抗力、系统故障或第三方服务异常；
  5. 你使用第三方嵌入服务时，第三方自身的数据处理行为。

6. Cookie 与类似技术

我们可能使用 Cookie 或类似技术用于维持登录状态、防止滥用、统计访问情况或优化服务。你可以通过浏览器设置管理 Cookie，但禁用后可能影响部分功能正常使用。

7. 第三方服务

当你使用 Desmos 等第三方学习网页、第三方 API 或其他外部服务时，你的数据可能受该第三方隐私政策约束。我们建议你仔细阅读相关第三方的隐私政策和使用规则。

我们对第三方服务的隐私保护、数据安全、内容准确性不承担责任。

8. 未来功能的隐私说明

如未来提供代码执行、AI 辅助学习、用户自有 API Key 接入或充值服务，我们可能会处理以下内容：

  1. 你提交的代码片段、提示词或学习内容；
  2. 与 AI 服务或代码执行相关的调用日志；
  3. 你自行配置的 API Key 标识信息；
  4. 充值记录、订单信息或账户余额信息。

对于你提供的自有 API Key，我们仅用于实现相应服务功能。你应自行确保该 Key 合法有效，并承担因 Key 泄露、滥用或第三方服务变更带来的风险。

9. 你的权利

你可以访问、更正或删除你的个人信息，也可以申请注销账号。你可通过 gfygo_@outlook.com 或网站内提供的功能行使上述权利。

在你提交账号注销申请后，我们将在 14 天 内删除或匿名化处理你的私人数据。超过 14 天后，我们不再负有保留或恢复数据的义务。

如法律法规要求我们保留某些日志或交易记录，我们将依法保留，但仅用于合规目的，并停止除存储和安全保护外的其他处理。

10. 已公开数据的处理

对于你已主动公开的内容，例如公开文档、公开分组、公开评论或其他已向社会公开的信息，在你注销账号后，我们无义务从第三方缓存、搜索引擎、转载页面或其他公开渠道中删除这些数据。

11. 未成年人保护

本平台主要面向学习用途。未成年人应在监护人指导下使用本平台。我们不会故意收集未成年人的敏感个人信息。如监护人发现未成年人未经同意提供个人信息，可联系我们处理。

12. 政策更新

我们可能根据法律法规、业务变化或技术升级更新本隐私政策。更新后，我们将通过网站内公告、站内通知或其他网站内方式通知你。

你继续使用本平台服务，即视为你已接受更新后的隐私政策。

13. 联系我们

如你对本服务条款或隐私政策有任何疑问，请通过以下方式联系我们：

  • 邮箱：gfygo_@outlook.com
  • 网站：gwl.net.cn
